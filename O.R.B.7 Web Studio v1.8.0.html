💡 HARDWARE DIAGNOSTICS GUIDE
• Configuration Sync: Confirms configuration and calibration data exchanged with the firmware. The firmware validates its EEPROM checksum during startup, but that checksum is not exposed to the Studio.
• Magnetic Balance: Measures the delta between opposing N/S/E/W Hall Effect sensor pairs. Absolute resting values vary with each mouse's magnet height and assembly, so they are shown for reference and do not determine alignment. Green (PERFECT) confirms all pair deltas are within 30 LSB.
• Sampling Frequency: Displays live USB WebHID streaming refresh rate (Target: 100 Hz).

Primary Device Controls

💡 PRIMARY CONTROLS ADJUSTMENT GUIDE
• Global Sensitivity: Master multiplier for all 6 degrees of freedom.
  – ▲ Increase (%): Moves camera faster across all 6 axes with less hand effort.
  – ▼ Decrease (%): Slows down all 6 axes for heavy, precise CAD manipulation.
• Global Deadzone: Continuously raises all six independent base gates after the 8→6 matrix and before axis sensitivity and the MOD curve.
  – 0% = 1×, 50% = 2×, 100% = 3× each configured base gate.
  – This comfort level is not a percentage of ADC range and does not filter individual sensors.
• Exclusive Mode:
  – ON: Locks output to Translation OR Rotation strictly (prevents accidental tilting while panning).
  – OFF: Allows full simultaneous 6DOF fluid motion (Pan + Rotate together).

1. Individual Axis Sensitivities (Q7)

💡 SENSITIVITY ADJUSTMENT GUIDE (Q7 DIVIDERS)
In the C++ fixed-point engine, sensitivity parameters act as mathematical dividers.
• ▲ Increase Value (e.g., 0.6 → 2.5): Decreases sensitivity. Axis moves SLOWER and requires larger physical displacement.
• ▼ Decrease Value (e.g., 2.0 → 0.5): Increases sensitivity. Axis moves FASTER with light hand effort.
(Use asymmetric Z settings to balance stiff TPU push-down vs light pull-up forces)

2. Axis Inversions & Swapping

🧭 STANDARD CAD DIRECTION & ORIENTATION GUIDE
• ON (Inverted): Reverses hardware signal direction. Reverses viewport camera movement.
• OFF (Normal): Preserves natural physical sensor polarity.
• Standard 3DConnexion Industry Defaults (SolidWorks, Fusion 360, Inventor):
  – Pan Left/Right (TX): Normal (OFF)
  – Pan Up/Down (TY): Inverted (ON)
  – Zoom In/Out (TZ): Inverted (ON)
  – Tilt Front/Back (RX): Normal (OFF)
  – Tilt Left/Right (RY): Inverted (ON)
  – Twist Left/Right (RZ): Inverted (ON)

3. Modifier Curves & Slopes (Q8)

📐 MODIFIER CURVE SLOPES ADJUSTMENT GUIDE
The MOD curve is unchanged and runs after the continuous global deadzone layer and axis sensitivity. There is no post-curve gate.
• Parameter A (Slope at Zero / Exponent 'a'):
  – ▲ Increase (e.g., 1.15 → 2.5): Flattens central response curve. Expands precision zone for millimeter micro-adjustments.
  – ▼ Decrease (e.g., 1.15 → 0.5): Makes initial movement immediate, sharp, and aggressive.
• Parameter B (Slope at End / Factor 'b' - Mode 3):
  – ▲ Increase (e.g., 1.35 → 1.55): Exponentially accelerates camera velocity near full deflection for rapid panning.
  – ▼ Decrease (e.g., 1.35 → 1.05): Makes end-of-travel acceleration smooth and linear.

1. Translation Base Gates

POST-MATRIX
⚡ TRANSLATION GATES
Each final translation axis has its own base gate in normalized matrix units. These values are neither ADC counts nor percentages. Values at or below the effective gate are suppressed before sensitivity and MOD processing.

2. Rotation Base Gates

💡 BASE GATES & GLOBAL DEADZONE
The global Deadzone setting scales TX, TY, TZ, RX, RY and RZ together without changing their independent base values: effective gate = base gate × (1 + 2 × deadzone / 100).

3. Exclusive Mode Tuning

💡 EXCLUSIVE HYSTERESIS PARAMETER GUIDE
• Switch Hysteresis Threshold: Force barrier required to break mid-motion dominance lock between Translation and Rotation.
  – ▲ Increase (e.g., 50 → 200): Requires significantly more intentional force to switch modes mid-motion. Prevents mode flickering for heavy hands.
  – ▼ Decrease (e.g., 50 → 15): Makes switching dominance between Translation and Rotation effortless with subtle hand pressure changes.

⚙️ Current 6DOF Processing Order

🛡️ SINGLE POST-MATRIX DEADZONE LAYER
1. 8→6 kinematic matrix: Produces the six final axes.

2. Continuous deadzone layer: Applies each axis base gate scaled by the global Deadzone level.

3. Axis sensitivity and MOD curve: Shape the surviving motion; the MOD mathematics is unchanged and no gate is applied after it.

4. Exclusive Mode: Optionally selects translation or rotation dominance using the configured hysteresis.
